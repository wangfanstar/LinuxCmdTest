# HtmlPasteGen 快捷复制页面生成器设计

## 目标

新增独立静态页面 `html/HtmlPasteGen.html`。用户在浏览器中填写页面名称、输出文件名、分组和复制条目后，可下载一个完全独立、可离线运行的快捷复制 HTML 文件。

生成后的页面默认只读，提供搜索、分组导航、点击复制与自定义快捷键；切换到编辑模式后可以修改内容、自动保存到当前浏览器，并可重新导出包含最新内容的 HTML 文件。

目标数据规模为 5–20 个分组、每组 5–30 条。生成器和成品页面均不使用第三方库、外部样式、网络请求或服务端接口。

本次只新增 `html/HtmlPasteGen.html` 及其针对性测试和文档，不修改工具首页或 C 服务端代码。

## 已确认的产品决策

- 生成页面采用“默认只读 + 可切换编辑模式”。
- 编辑后的数据自动保存在当前浏览器，并可重新导出最新版 HTML。
- 生成器采用三栏工作台：左侧内容结构、中间录入编辑、右侧成品预览。
- 生成器本身和生成的成品都是单文件、无网络依赖的 HTML。
- 用户粘贴的标题、内容和备注全部按纯文本处理，不执行其中的 HTML 或脚本。
- 快捷键允许自定义组合键，例如 `Alt+1`、`Ctrl+Shift+A`；输入控件获得焦点时暂停触发。

## 页面与视觉结构

### 生成器顶部

顶部依次提供：

- 返回工具首页的链接；
- 工具名称和“所有数据仅在浏览器本地处理”说明；
- 页面名称；
- 输出文件名；
- 草稿保存状态；
- 主操作“生成 HTML”。

文件名自动补全 `.html`，同时清理 Windows、Linux 和 macOS 常见非法文件名字符。页面名称不能为空。

### 三栏工作台

桌面端工作区包含三个职责明确的区域：

1. **内容结构栏**：列出分组和每组条目数，支持新增、选择、重命名、复制、删除和上下移动分组。
2. **条目编辑栏**：编辑当前分组。每条数据包含标题、复制内容、快捷键、可选备注和收藏状态；支持连续新增、复制、删除、折叠和上下移动条目。
3. **成品预览栏**：使用当前数据实时模拟生成页面的分组、搜索和复制卡片，可直接测试复制按钮与快捷键显示。

窄屏下三栏改为“结构 / 编辑 / 预览”三个页签，每次显示一个主区域；主要按钮保持足够触控尺寸。

### 辅助操作

工具栏提供：

- JSON 导出，用于显式备份生成器草稿；
- JSON 导入，校验通过后替换当前草稿；
- 新建空白项目；
- 恢复示例项目；
- 全部展开或折叠条目。

浏览器本地草稿自动保存。存储不可用或超出配额时，页面保留当前内存数据并提示用户导出 JSON 或直接生成 HTML，不阻塞主要流程。

## 生成页面体验

### 默认只读模式

生成页面顶部显示页面名称、全局搜索框、主题切换、编辑模式开关和“刚刚复制”状态。左侧是带数量的分组导航，主区域显示当前筛选结果。

每张复制卡片显示标题、内容摘要、可选备注、收藏状态、快捷键标签和复制按钮。点击卡片非交互区域或复制按钮都会复制完整原文。复制成功后卡片和页面状态区提供文字反馈；失败时显示可选择的原文并说明可手动复制。

搜索匹配分组名、条目标题、复制正文和备注，忽略大小写。按 `/` 聚焦搜索，按 `Escape` 清空搜索。页面提供“仅看收藏”“全部展开/折叠”控制。手机端分组栏变为抽屉式导航。

### 快捷键

用户可输入由 `Ctrl`、`Alt`、`Shift`、`Meta` 与一个普通按键组成的组合，也可输入功能键。保存时进行规范化，例如将 `ctrl + shift + a` 统一显示为 `Ctrl+Shift+A`。

同一页面内快捷键必须唯一。仅修饰键、未知按键、与工具自身操作冲突的组合以及高风险浏览器保留组合会被拒绝或要求清除。生成页面在文本输入框、文本域和可编辑区域获得焦点时暂停条目快捷键，避免妨碍输入。

### 编辑模式

进入编辑模式后，分组和卡片出现新增、修改、复制、删除和排序操作。编辑结果使用文档 ID 作为本地存储命名空间，不覆盖另一个生成页面的数据。

编辑模式工具栏提供“导出最新版 HTML”和“恢复文件原始内容”。恢复操作清除本地覆盖并回到文件内嵌的初始数据，执行前必须二次确认。若本地存储不可用，编辑仍可进行，但明确显示“尚未持久化”，并引导用户导出最新版文件。

## 数据模型与组件边界

页面数据使用带版本号的纯对象模型：

```text
document
├─ schemaVersion
├─ documentId
├─ meta: title, filename, themePreference
└─ groups[]
   ├─ id, title, collapsed
   └─ items[]
      └─ id, title, content, shortcut, note, favorite, collapsed
```

分组和条目使用稳定随机 ID。重名不会影响排序、选择或编辑。状态逻辑分为以下单元：

1. 数据模型：创建、复制、删除、重排和不可变快照。
2. 校验与迁移：检查导入数据、补齐缺省字段并拒绝不支持的未来版本。
3. 快捷键：解析、规范化、冲突检查和键盘事件匹配。
4. 持久化：生成器草稿、成品页面本地覆盖和异常降级。
5. 渲染：结构栏、编辑器、预览与生成页面视图。
6. 复制：优先使用 Clipboard API，失败时使用兼容回退并提供手动复制路径。
7. 文件输出：生成 JSON 备份或独立 HTML Blob，触发下载后释放临时 URL。

## 生成与重新导出流程

生成器的数据流为：

`表单输入 → 更新内存模型 → 自动保存草稿 → 实时校验和预览 → 安全序列化 → 嵌入成品运行时 → 下载指定文件名`

成品编辑后的数据流为：

`进入编辑模式 → 修改当前模型 → 保存浏览器覆盖 → 重新安全序列化 → 嵌入同一成品运行时 → 下载最新版 HTML`

成品运行时只维护一套模板和逻辑。生成器首次导出与成品再次导出调用同一序列化规则，避免功能逐次丢失。

用户数据嵌入专用 JSON 数据块，并转义 `<`、`>`、`&`、Unicode 行分隔符和可能形成结束标签的序列。渲染时统一使用 `textContent` 或 DOM 属性，不把用户文本拼入 `innerHTML`。

## 校验与异常处理

- 页面名称、分组名称和条目标题必须包含非空白字符。
- 允许复制正文为空，但在条目和生成操作处显示警告，防止误生成无内容按钮。
- 快捷键为空表示仅支持点击复制；非空时必须可解析且不与其他条目冲突。
- 删除分组、新建空白项目、恢复示例、恢复成品原始内容均需要确认。
- JSON 导入必须先完整解析、校验和迁移；失败时保留当前草稿不变，并指出具体字段错误。
- 文件名为空时使用 `quick-copy.html`；非法字符替换为连字符，并限制过长名称。
- 下载或剪贴板调用失败时显示持续可见的错误，不只依赖短暂提示。
- 生成内容过大时显示文件体积提示，但不任意丢弃用户数据。
- 本地存储损坏时保留内嵌初始数据，并提供忽略损坏数据与清除本地覆盖的选项。

## 易用性细节

- 初次打开提供包含两个分组的可删除示例，让用户立即理解填写方式。
- 在条目末尾按 `Ctrl+Enter` 快速新增下一条；新增后焦点进入标题。
- 所有危险操作使用文字说明目标对象，不使用含义不明的图标按钮。
- 拖放排序不作为唯一方式，同时提供键盘可用的上移和下移按钮。
- 状态消息使用 `aria-live`，成功、警告和错误同时通过文字、图标和颜色表达。
- 焦点样式清晰，快捷键、复制按钮和编辑控件均可用键盘操作。
- 深浅主题遵循系统设置，也允许用户手动切换；主题选择本地保存。

## 验证方案

自动化测试覆盖：

- 文件名补全、非法字符替换和默认文件名；
- 数据模型的新增、复制、删除和重排；
- 快捷键规范化、无效组合与重复冲突；
- JSON 导入导出和版本迁移一致性；
- 用户文本安全转义，包括 `</script>`、HTML 标签和 Unicode 分隔符；
- 生成文件包含内嵌数据、完整运行时和离线样式；
- 生成文件不引用外部脚本、样式、字体或网络资源；
- 搜索匹配规则和收藏筛选；
- 本地存储失败时的非阻塞降级；
- 剪贴板 API 失败时进入回退路径。

浏览器人工验证覆盖：

- 桌面三栏布局与窄屏页签布局；
- 连续录入、分组切换、排序、删除确认和草稿恢复；
- 点击复制、快捷键复制、搜索、收藏筛选与主题切换；
- 成品编辑、本地自动恢复、恢复初始内容和重新导出；
- 重新导出的文件可再次编辑和导出；
- 粘贴恶意 HTML 或脚本字符串时只显示纯文本；
- Chrome、Edge 和 Firefox 的本地文件打开流程。

## 不在本次范围内

- 不把数据上传到服务端或云端。
- 不提供多人协作或跨设备自动同步。
- 不解析 Markdown、富文本或可执行 HTML。
- 不支持附件、图片或二进制文件复制。
- 不为上千条数据实现虚拟列表。
- 不修改 `html/index.html` 添加入口。
