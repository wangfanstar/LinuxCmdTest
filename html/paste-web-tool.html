CentOS Pastebin 上传与恢复工具

本工具支持一键发布/恢复、网页表单自动提交与书签脚本 URL 回填；不保存密码，不自动登录。

CentOS Pastebin 书签脚本
将左侧按钮拖到浏览器书签栏。创建页点击它可填入剪贴板内容和 1 天有效期；结果页点击它可回填网址；恢复下载时可从当前 paste 页面采集正文。
帮助说明

发布文件

  1. 选择文件或文件夹后点「一键发布」，工具会自动逐条网页提交并等待 URL 回填。
  2. 小型或中型多文件集合可先点「单 Paste 打包」，把整个文件集压成 1 条 Paste，恢复时自动展开。
  3. 默认免 API key；每条弹出结果页点 1 次书签脚本即可回传 URL。
  4. 配置 API Key + 本地代理后可实现全程无书签自动发布（见下方高级设置）。
  5. 也可分步使用「网页提交下一个」「准备填表」手动控制。

恢复文件

  1. 粘贴结果 CSV 后点「一键恢复」，工具会自动尝试下载并保存到指定文件夹。
  2. 遇到跨域限制时会自动打开 raw 采集页；在弹出页点击书签脚本即可回传正文。
  3. 全部采集完成后默认保存到指定文件夹；Base64 内容按当前统一模式或 CSV 元数据解码。
  4. 也可分步使用「导入文本」「自动下载」「保存到指定文件夹」或「保存 ZIP」手动控制。

结果与状态

  • “复制结果表”用于普通 CSV 备份。
  • “复制结果表(Base64)”适合贴到聊天、工单或其他会破坏换行的地方。
  • Base64 模式恢复时请选择带“Base64 解码”的保存按钮。
  • 刷新页面后本地状态会保留；内容丢失时重新选择文件即可继续。
