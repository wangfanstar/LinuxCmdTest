# File 与 Base64 转换工具设计

## 目标

新增一个独立静态页面 `html/file2base64.html`，在浏览器本地完成任意文件与纯 Base64 字符串之间的双向转换。页面应让首次使用者无需阅读说明即可完成文件选择、结果复制或文件恢复，并明确说明文件不会上传。

本次不修改工具首页、服务端路由或其他现有页面。

## 已确认的产品决策

- Base64 输出只使用纯 Base64 字符串，不添加 Data URL 前缀。
- 文件转 Base64 不限制扩展名；页面以 Excel 文件为主要使用场景，但按原始二进制处理所有文件。
- 采用“双模式单任务”布局：顶部在“文件转 Base64”和“Base64 转文件”之间切换，每次只显示当前任务。
- 目标文件名为 `file2base64.html`。
- 单页、无第三方依赖、无网络请求，可离线运行。

## 用户界面

### 页面框架

页面顶部显示工具名称、简短用途说明、返回工具首页的链接，以及“全程本地处理，不上传文件”的隐私提示。其下使用分段式切换按钮展示两个转换方向。桌面端使用居中的单列卡片；窄屏下控件保持同一顺序并占满可用宽度。

### 文件转 Base64

主要输入区是可点击、可拖放的文件选择框。选择文件后自动开始转换，不要求用户再次点击“开始”。完成后显示：

- 原文件名；
- 原文件大小；
- Base64 结果大小；
- 转换状态；
- 可滚动、可选择的只读 Base64 结果区。

“复制 Base64”是唯一强调色主按钮；“下载 .txt”“更换文件”和“清空”使用次要样式。复制成功、复制失败、读取失败等结果通过邻近状态消息反馈，不依赖容易错过的临时弹窗。

### Base64 转文件

主要输入区是支持粘贴长文本的 Base64 文本框。文件名输入框默认值为 `decoded.xlsx`，用户可根据原始文件类型修改文件名和扩展名。主按钮为“转换并下载”，另提供“清空”。输入发生变化后，之前的成功状态失效，避免误认为旧结果仍对应当前内容。

## 数据流与组件边界

页面中的 JavaScript 按职责分为以下逻辑单元：

1. 模式与界面状态：切换转换方向、更新文件信息、状态消息和按钮可用性。
2. 文件读取：通过浏览器文件 API 获取 `ArrayBuffer`，不解析文件内容。
3. Base64 编码：将字节数组分块转换为二进制字符串，再调用浏览器 Base64 编码能力，避免一次展开大型数组造成调用栈溢出；在分块之间让出主线程，以便更新进度和响应取消操作。
4. Base64 清理与校验：移除空白和换行，检查字符集、长度和末尾填充后再解码。
5. 文件下载：从解码后的字节生成 `application/octet-stream` Blob，使用临时对象 URL 触发下载并及时释放。
6. 剪贴板：优先使用 Clipboard API；不可用或被拒绝时，回退到选中文本和 `execCommand('copy')`。

文件转 Base64 的数据流为：选择或拖放文件 → 读取二进制 → 分块编码 → 显示文件信息和结果 → 复制或下载文本。

Base64 转文件的数据流为：粘贴 Base64 → 清理空白 → 校验 → 解码成字节 → 使用用户指定文件名下载。

## 校验与异常处理

- 空文件是合法输入，其 Base64 结果为空字符串；界面仍显示转换成功和文件大小为 0 B。
- Base64 输入为空时不允许下载，并提示先粘贴内容。
- Base64 输入允许空格、制表符和换行，校验前统一移除。
- 拒绝非法字符、不正确的长度以及不合法的 `=` 填充，并给出明确提示。
- 文件读取失败、解码失败、下载失败和剪贴板写入失败分别处理，不显示笼统的未知错误。
- 大文件不强制禁止；选择超过 50 MB 的文件时显示内存占用提示。转换仍由用户当前操作继续完成。
- 读取和编码期间显示进度与取消按钮；取消后终止当前任务、释放中间数据并回到可重新选择文件的状态。
- 新转换开始时清除旧结果和旧状态，防止内容混淆。
- 拖放区域阻止浏览器默认打开文件的行为，并在拖入时提供可见反馈。

## 可访问性与响应式要求

- 所有输入、按钮和状态消息具有可读标签；模式切换使用适当的 ARIA 状态。
- 键盘用户可以选择文件、切换模式、聚焦结果并执行复制或下载。
- 状态消息使用 `aria-live`，同时通过文字和颜色表达状态。
- 焦点样式清晰，文本与背景保持足够对比度。
- 移动端按钮改为整行或易点击的网格布局，Base64 文本区保持合理最小高度。

## 验证方案

自动化检查覆盖页面关键元素与核心函数，并验证：

- 普通二进制文件编码后再解码，结果逐字节一致；
- 空文件可正常转换；
- 带空格和换行的合法 Base64 可恢复；
- 非法字符、错误长度和错误填充会被拒绝；
- 中文文件名可显示，下载文件名可编辑；
- 选择与拖放走同一转换路径；
- 转换进度可见，取消后不会遗留可复制的半成品结果；
- Clipboard API 失败时可进入复制回退路径；
- 页面不引用外部脚本、样式或网络资源。

人工浏览器检查覆盖桌面和窄屏布局、拖放反馈、长 Base64 滚动、成功与错误状态、复制以及下载后的二进制一致性。

## 不在本次范围内

- 不解析或预览 Excel 工作表内容。
- 不保存转换历史。
- 不将文件或 Base64 上传到服务器。
- 不支持批量文件或压缩打包。
- 不修改 `html/index.html` 添加入口。
