# 自定义测试命令组合

在 `HtmlPasteGen.html` 左侧点击“组合多选”，勾选需要的条目。可跨分组选择，也可以使用组标题旁的复选框选择整组（包括子条目）。单个条目复选框只选择该条目本身。默认按勾选顺序组合。

点击“组合已选条目”，输入组合名称。编辑窗支持修改每一步名称与内容、上下移动、删除步骤、增加自定义步骤，以及选择换行、空行、空格或自定义分隔符。预览会显示最终复制的完整文本。点击“返回左侧选条目”可保留当前编辑草稿，选好后点击“继续编辑组合”追加。

保存后，命令出现在“自定义组合”分组，并在左侧“自定义组合”列表中提供编辑、删除入口。也可在主编辑区点击“编辑组合”。标题、备注、快捷键、收藏、复制条目等沿用现有编辑功能。删除组合不删除来源条目。

组合保存的是步骤内容的独立快照，之后修改或删除来源条目不会改变已保存的组合。程序只生成和复制文本，不执行任何测试命令。

JSON 沿用 schemaVersion 2：组合仍是普通条目，额外保存 `composition: { separator, parts }`；`content` 保存组合的完整文本。旧版 schemaVersion 1/2 JSON 仍可导入。生成的 HTML 会显示组合卡片、步骤数，并支持搜索、单行/选中/全部复制及多选复制。成品页直接编辑组合完整正文时，会将它保存为单一步骤；如需保留多步骤结构进行调整，请将 JSON 导回 HtmlPasteGen 使用“编辑组合”。

布局同步完成：工作台最大宽度 1880px，左侧默认 330px；分隔条支持鼠标拖动、方向键（Shift 加大步长）、Home/End 和双击恢复默认。宽度偏好保存在本机，较窄屏幕会自动限制列宽，手机隐藏分隔条。左侧目录和预览各自滚动；普通屏幕的录入助手停靠底部。

验证命令：

```sh
node tests/html_paste_composition_test.js
node tests/html_paste_gen_test.js
node tests/html_paste_gen_ui_test.js
```

使用 `node tests/html_paste_composition_test.js --serve` 可启动仅监听本机、只读的浏览器验收服务。它提供编辑器和 `/composition-test.html` 示例成品，不写入网络库，也不使用正式站点的草稿存储。
