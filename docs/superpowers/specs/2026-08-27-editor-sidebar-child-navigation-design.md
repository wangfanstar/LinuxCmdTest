# HtmlPasteGen 编辑器子条目导航设计

## 目标

在 `HtmlPasteGen.html` 左侧“内容结构”面板中，为每个分组增加可折叠的子条目导航，让长文档可以快速定位到具体条目，同时保持现有分组选择、排序和编辑能力。

## 交互设计

- 每个分组行显示一个展开/收起按钮、分组选择按钮和原有的上下移动按钮。
- 子条目导航默认折叠，首次打开页面时不展开任何分组；切换项目、导入 JSON 或清空/恢复项目后也回到默认折叠状态。
- 展开后按当前文档顺序列出该分组的条目序号和标题；标题过长时省略显示，完整标题通过 `title`/辅助标签保留。
- 点击子条目直接选中该分组并滚动到右侧对应编辑卡片，自动展开该分组的导航，焦点落在条目标题输入框。
- 折叠/展开只改变瞬时界面状态，不写入文档 JSON，不影响生成 HTML 的内容。
- 没有条目的分组仍可展开，但显示“暂无子条目”提示，避免空白区域造成误解。
- 使用按钮语义和 `aria-expanded`、`aria-controls`，键盘可操作；左侧面板已有独立滚动条，子导航不改变页面整体滚动行为。

## 实现约束

- 复用现有事件委托 `handleAction`、`selectAndFocus`、`createElement` 和 `makeButton`，不引入框架或外部依赖。
- 用 `Set` 保存展开的分组 ID，作为编辑器瞬时状态；渲染时只保留当前存在的分组 ID。
- 保持 `group-row` 的现有视觉层级和分组操作按钮，新增子导航使用紧凑缩进和可见的左侧层级线。

## 验证策略

- UI 契约测试断言子导航类名、展开动作、条目选择动作、默认折叠状态和 ARIA 属性存在。
- 运行现有核心/UI/网络库/索引/重启测试、`git diff --check` 与 `wsl make`，确保生成 HTML 和服务端不受影响。
- 手动回归：打开编辑器确认所有分组折叠；展开分组并点击多个子条目；导入 JSON、清空项目和恢复示例后确认重新折叠；键盘触发展开和条目定位。
