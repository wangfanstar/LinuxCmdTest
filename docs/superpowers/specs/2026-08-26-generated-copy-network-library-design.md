# 生成 HTML 复制与网络库交互设计

## 目标

扩展 `HtmlPasteGen.html` 及其生成页面：让命令支持单行、选中片段、全部内容三种复制方式；让项目与网络库工具在长页面中保持可用；将网络库搜索和预览改为按需弹出的固定面板；一次导出同名 HTML 与 JSON 文件。

## 交互设计

### 生成页面复制

- 每张命令卡片继续支持点击卡片复制全部内容。
- 命令正文按换行拆成可点击的行，点击某行复制该行原文（保留缩进，不额外添加换行）。
- 卡片增加“复制选中”和“复制全部”操作。
- “复制选中”只接受当前卡片命令正文中的选区；没有选区、选区跨出当前正文或选区为空时给出提示，不改写剪贴板。
- 单行、选中、全部复制都使用统一成功状态：卡片变色、状态栏播报；批量复制仍保留复制篮流程。

### 编辑器固定工具

- 编辑器项目工具栏吸顶，项目 JSON 导入、导出以及清空等操作在长页面中保持可见。
- 项目工具栏增加“网络库”入口；网络库本体默认隐藏，不占用编辑器页面高度。
- 打开网络库后显示固定的弹出面板，面板头部包含关闭、刷新、新建 JSON、导入、导出与覆盖选项；面板内容区独立滚动。
- 搜索框、类型筛选、文件列表与 HTML 预览只在网络库面板打开时显示。
- 打开/关闭支持按钮和 Escape 键，`aria-expanded` 与 `aria-hidden` 始终同步；关闭时保留筛选和当前选择状态。

### 网络库导出

- “导出到网络库”使用当前文档生成同名 `.html` 与 `.json`。
- 保存前根据当前网络库列表检查两种文件名；未勾选覆盖且任一同名文件存在时，不发起写入并提示用户。
- 勾选覆盖时只确认一次，然后按 JSON、HTML 顺序保存；任一步失败都明确提示已完成和未完成的文件，避免静默失败。
- 成功后刷新网络库列表，使新文件立即出现在列表与预览中。

## 数据与兼容性

- 不改变文档 JSON schema；生成页复制状态、弹窗开关和筛选条件均为瞬时 UI 状态，不写入文档。
- 保留现有网络库 API 路由与文件名校验；HTML 文件在浏览器中继续只读，但成套导出时允许保存受限的 `.html` 文件；JSON 文件继续支持导入、编辑、删除。
- 现有项目 JSON 导入/导出仍保持本地文件下载语义；网络库导入仍需确认替换当前编辑内容。
- 在 `file:` 协议下网络库面板仍显示不可用提示，不影响本地生成 HTML 与 JSON。

## 验证策略

- UI 契约测试检查三种复制控件、选区校验、固定项目工具栏、弹出网络库结构与默认隐藏状态。
- 生成模板测试检查单行拆分、选中复制、全部复制函数以及网络库固定工具栏和导出双文件逻辑。
- 现有核心模型、网络 API、索引导航测试和 `wsl make` 必须继续通过。
- 手动浏览器回归覆盖：长命令单行复制、跨段选区拒绝、面板打开/关闭/Escape、长网络库滚动、双文件导出冲突提示。
