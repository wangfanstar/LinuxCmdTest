# HtmlPasteGen 编辑区与长命令展示调整

## 目标

优化 `html/HtmlPasteGen.html` 工具工作台的桌面编辑体验：缩窄结构导航、扩宽条目编辑区和命令正文输入区；将快捷键与备注放入同一个元信息栏；解决预览卡片过窄导致长命令无法看全的问题。

## 已确认的布局方案

采用 A「均衡扩宽」方案：

- 左侧结构栏保留分组导航与操作按钮，但从当前比例适度收窄；
- 中间编辑栏获得主要宽度，适合录入长命令；
- 右侧预览栏保留足够的卡片宽度，用于快速验证成品；
- 窄屏继续使用现有结构/编辑/预览移动标签，不改变移动端的信息架构。

## 编辑字段布局

每个条目编辑卡片保持标题、正文和收藏功能不变，字段调整为：

1. 标题：独立一行；
2. 快捷键与备注：合并为一个“快捷键 / 备注”元信息栏，内部上下排列两个独立输入控件，快捷键冲突提示紧跟快捷键输入；
3. 复制内容：独占整行，使用更大的文本输入区，默认最小高度提升，命令较长时可继续拖动扩展；
4. 收藏：保留在元信息区域下方或同一栏的末端，保持原数据字段与事件回写不变。

合并只改变视觉布局，不合并数据模型：`shortcut` 和 `note` 仍是两个独立字段，导入、导出、快捷键校验和自动保存逻辑保持兼容。

## 预览长命令展示

预览卡片继续使用摘要以维持多卡片扫描效率，但对正文增加独立显隐状态：

- 卡片正文超过摘要阈值时显示“显示全部命令”按钮；短正文不显示多余按钮；
- 点击后在当前卡片内展开完整正文，按钮变为“收起命令”；
- 展开状态只属于当前工作台预览会话，不写入文档模型、不进入导出 JSON 或生成 HTML；
- 点击卡片复制仍复制完整 `item.content`，显隐按钮不会触发复制；
- 搜索、收藏筛选或编辑内容导致预览重绘时，失效条目的展开状态自动清理。

## 实现边界

- 修改范围限定在 `html/HtmlPasteGen.html` 与其 UI 契约测试；不修改 C 服务端和生成成品页的批量复制功能；
- 继续使用现有 `createElement`、`textContent` 和事件委托，不引入外部依赖或 `innerHTML`；
- 现有三栏断点和移动端标签保留，桌面布局调整只改变比例与最小宽度；
- 现有编辑顺序、收藏、快捷键、备注、草稿保存、JSON 导入导出和 HTML 生成行为保持兼容。

## 验证标准

- UI 测试检查新的桌面网格比例、合并元信息栏、命令区最小高度和长命令展开控件；
- 生成器脚本语法检查通过，现有核心/UI 测试继续通过；
- 浏览器确认长命令卡片可展开/收起，显隐按钮不触发复制，编辑快捷键与备注仍分别写回正确字段；
- `git diff --check` 与 Linux `make` 通过。
