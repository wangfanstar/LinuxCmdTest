# HtmlPasteGen 批量复制与层级导航增量设计

## 目标

扩展 `html/HtmlPasteGen.html` 生成的独立快捷复制页面，增加多选、一键批量复制、临时复制顺序调整、正文统一及单条显隐，以及“分组 → 条目标题”两级导航。

现有单击卡片复制、条目快捷键、搜索、收藏、主题、编辑模式、本地保存和重新导出能力保持不变。

本次修改生成器内嵌的成品页面模板、相关纯函数和自动化测试，不修改 C 服务端或工具首页。

## 已确认的产品决策

- 每张复制卡常驻独立复选框；勾选负责批量选择，点击卡片主体仍然单条复制。
- 选中条目后显示底部固定复制篮。
- 复制篮支持拖动排序，并提供上移、下移按钮作为键盘与触屏替代方式。
- 批量拼接默认使用一个换行，同时支持空行、空格和自定义分隔符。
- 复制篮排序只影响本次批量复制，不改变原数据顺序。
- 编辑模式中的上移、下移继续负责永久排序；修改自动保存并进入重新导出的 HTML。
- 正文默认隐藏；顶部可以统一显示或隐藏，每张卡也可独立显示或隐藏。
- 左侧导航采用“分组标题 → 条目标题”两级结构。

## 成品页面交互

### 卡片选择与单条复制

复制卡片左上角显示复选框，标签为“选择：条目标题”。复选框的点击和键盘操作只改变批量选择状态，并阻止事件冒泡到卡片，避免意外触发单条复制。

卡片其余区域保持原有点击复制与 Enter/Space 键复制行为。自定义条目快捷键同样继续执行单条复制，不改变选择状态。

选中的卡片显示清晰边框、背景和顺序编号。左侧条目子导航同步显示选中标记。

### 复制篮

首次选中条目时，页面底部出现固定复制篮。复制篮包含：

- 已选数量；
- 按当前复制顺序排列的条目标题；
- 每条的拖动手柄、顺序编号、上移、下移和移除按钮；
- “选择当前结果”和“清空”操作；
- 分隔符选择；
- 自定义分隔符输入框，仅在选择“自定义”时显示；
- 主操作“一键复制”。

条目第一次被选择时追加到复制篮末尾。取消选择或从复制篮移除时，同时从选择集合和顺序列表删除。再次选择同一条目时追加到当前队列末尾，不产生重复项。

搜索、收藏筛选、滚动和分组切换不清空复制篮。选择当前结果只加入当前可见且未选中的条目，并按页面显示顺序追加。

复制篮支持 HTML5 拖动排序。拖动不可用或不便使用时，上移和下移按钮提供相同行为。复制篮只调整临时队列，不修改文档模型。

### 批量拼接与复制

批量复制按复制篮顺序取得每条完整正文。分隔符规则为：

- 换行：`\n`；
- 空行：`\n\n`；
- 空格：单个普通空格；
- 自定义：用户输入的原始字符串，允许为空。

正文为空的条目不参与最终拼接。复制完成后状态区报告已复制条数；若跳过空正文，同时报告跳过数量。所有选中条目均为空时不写入剪贴板，并提示先补充内容或改选其他条目。

批量复制优先使用 Clipboard API，失败时沿用现有离屏文本域与 `execCommand('copy')` 回退。再次失败时显示明确的手动复制提示。

### 正文显隐

成品页初始不渲染可见正文，只显示标题、备注、收藏、快捷键和复制操作。顶部按钮文字为“显示全部内容”；点击后展开全部当前卡片，并变为“隐藏全部内容”。

每张卡提供独立的“显示内容/隐藏内容”按钮。统一显示后，单条仍可独立隐藏；统一隐藏后，单条仍可独立显示。实现上以每条最终可见状态为准，而不是让两个控制互相覆盖用户选择。

显隐只影响界面。单条复制、快捷键复制、批量复制、搜索、编辑和导出的数据始终使用完整正文。

### 两级导航

左侧导航中，分组标题为一级，当前筛选后可见的条目标题为二级。条目标题使用可点击锚点，点击后滚动到对应卡片并添加短暂高亮，同时保持键盘焦点清晰。

条目子标题显示选择状态和在复制篮中的顺序编号。搜索或收藏筛选隐藏的条目不显示在导航中，但已经选中的条目继续保留在复制篮。

窄屏下沿用现有“浏览分组”抽屉入口，抽屉中同样展示两级层级。点击条目后关闭移动端导航并滚动到卡片。

## 状态与数据流

批量与显隐使用成品页面运行时状态：

```text
selectionState
├─ selectedIds: Set<itemId>
├─ copyOrder: itemId[]
├─ revealedIds: Set<itemId>
├─ hiddenIds: Set<itemId>
├─ revealAll: boolean
├─ separatorMode: newline | blankLine | space | custom
└─ customSeparator: string
```

条目正文的最终可见状态为：若 ID 在 `revealedIds` 中则显示；若 ID 在 `hiddenIds` 中则隐藏；否则跟随 `revealAll`。

`revealedIds` 与 `hiddenIds` 必须互斥。单条执行“显示”时先从 `hiddenIds` 删除再加入 `revealedIds`；执行“隐藏”时执行相反操作。统一显隐会清空两个覆盖集合后更新 `revealAll`。

批量复制数据流为：

`卡片勾选 → selectedIds 去重 → copyOrder 追加/删除 → 复制篮排序 → 解析分隔符 → 按顺序取得有效正文 → 拼接 → 剪贴板写入 → 状态反馈`

这些状态是当前页面会话的临时界面状态，不写入文档模型，不进入本地数据覆盖，也不嵌入重新导出的 HTML。刷新页面后选择、临时顺序和显隐状态重置。

永久排序继续通过编辑模式直接调整 `model.groups[].items`，随后保存浏览器覆盖并由重新导出功能写入新文件。

## 一致性与异常处理

- 选择集合和复制顺序必须始终一一对应且无重复 ID。
- 条目在编辑模式中删除时，从 `selectedIds`、`copyOrder`、`revealedIds` 和 `hiddenIds` 同步移除。
- 分组删除时同步清理其中所有条目的临时状态。
- 本地覆盖数据加载后若不存在某个已选 ID，渲染前自动清理该无效 ID。
- 拖动目标无效时不改变原顺序。
- 队列首项禁用上移，末项禁用下移。
- “选择当前结果”在没有可见条目时禁用或给出无可选内容提示。
- 自定义分隔符为空是合法配置，界面明确显示“内容将直接连接”。
- 正文显隐不通过 `innerHTML` 插入数据，继续使用 `textContent`，避免执行用户内容。

## 可访问性与响应式要求

- 复选框、显隐按钮、复制篮排序按钮和导航子标题都有包含条目标题的可读标签。
- 复制篮使用有序列表表达当前顺序，并通过 `aria-live` 报告选择、排序和复制结果。
- 拖动不是唯一排序方式；所有功能可只用键盘完成。
- 底部复制篮不得遮住最后一组卡片，页面在复制篮显示时增加对应底部留白。
- 手机端复制篮可折叠为摘要栏；展开后使用全宽面板，主要按钮保持至少 44px 高。
- 两级导航的一级和二级在视觉上有明确缩进与字号差异。

## 验证方案

自动测试覆盖：

- 批量文本按指定 ID 顺序拼接；
- 换行、空行、空格、自定义和空自定义分隔符；
- 空正文被跳过及全部为空时拒绝复制；
- 选择去重、取消选择、重新选择追加到末尾；
- 队列上移、下移和非法目标不改变顺序；
- 删除条目或分组后同步清理临时状态；
- 成品模板包含复选框、复制篮、统一及单条显隐控件；
- 两级导航包含分组与条目锚点；
- 现有单条复制、快捷键、编辑和重新导出契约继续存在；
- 页面仍为无外部依赖单文件。

真实浏览器验证覆盖：

- 单击复制与复选框互不触发；
- 多选、取消、选择当前结果、清空；
- 拖动及按钮排序后剪贴板文本顺序一致；
- 四种分隔符和空正文反馈；
- 顶部统一显隐与单条显隐组合；
- 两级导航滚动、高亮和选择编号；
- 搜索后复制篮保留已选条目；
- 编辑删除同步清理选择；
- 桌面和窄屏复制篮布局。

## 不在本次范围内

- 不把临时复制篮状态保存到浏览器或导出文件。
- 不跨多个生成页面共享选择。
- 不增加服务端剪贴板、云同步或操作历史。
- 不改变生成器三栏工作台的数据结构。
