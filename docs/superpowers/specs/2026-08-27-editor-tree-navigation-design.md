# HtmlPasteGen 真实树形目录导航设计

## 目标

将 `HtmlPasteGen.html` 左侧目录从“分组下的扁平条目”升级为最多 4 级的真实树形目录。每个节点都保留完整的可复制条目能力；有子节点的条目可展开、收起和调整层级，编辑区、生成 HTML、搜索、批量复制和 JSON 网络库统一使用同一棵树。

## 设计决策

### 数据模型

文档 schema 升级到新版本，不做旧 JSON 兼容迁移。分组仍持有根节点，条目统一使用递归 `children`：

```json
{
  "id": "item-xxx",
  "title": "查看服务状态",
  "content": "systemctl status nginx",
  "shortcut": "Alt+1",
  "note": "Linux",
  "favorite": false,
  "link": "",
  "collapsed": false,
  "children": []
}
```

- `children` 缺失或不是数组时，JSON 校验失败并保留当前草稿。
- 节点最大深度为 4，节点 ID 必须全树唯一，快捷键必须全树不冲突。
- 将树操作集中为纯函数：递归遍历、路径查找、后代计数、同级上下移动、缩进、反缩进、复制子树和删除子树。
- 目录展开状态属于编辑器或生成页的瞬时 UI 状态，不写入 JSON；现有 `collapsed` 字段只控制编辑区命令正文是否折叠，二者互不影响。所有文档替换操作后目录默认折叠。

### 编辑器交互

- 左侧每个节点显示展开/收起箭头、标题、后代计数、层级徽标、`−` 和 `＋`。
- `＋`（降低层级）把节点移动到前一个同级节点的 `children` 下；没有前置同级节点或已到第 4 级时禁用。
- `−`（提升层级）把节点移动到当前父节点的下一个同级位置；根节点禁用。
- 上移/下移只影响当前父节点的 `children` 顺序。
- 点击节点标题定位右侧编辑卡片，并自动展开全部祖先；编辑区递归缩进展示节点。
- 每个节点都支持添加子条目、添加同级条目、复制整棵子树和删除整棵子树。删除前提示后代数量，复制子树会为全部后代生成新 ID 并清空快捷键。
- 左侧导航默认折叠，提供“展开全部/折叠全部”；统一操作只影响导航展开状态，不改变条目正文的 `collapsed` 状态。
- 层级变化后立即重绘左侧导航、编辑区、预览、搜索统计和校验提示；禁用操作不改变数据并给出可理解的提示。

### 生成 HTML 与批量行为

- 生成模板递归渲染树形导航，每个节点链接到自己的命令卡片；导航默认折叠。
- 命令卡片继续默认全部显示，保持现有生成页面行为；导航展开仅控制目录，不隐藏命令内容。
- 点击树节点导航滚动到对应卡片并高亮定位；父节点显示后代计数。
- 批量复制、复制顺序和自定义内容插入使用统一的树遍历结果；用户显式调整后的顺序优先于默认深度优先顺序。

### JSON 与网络库

- 本地 JSON、网络库 JSON 和生成 HTML 内嵌 JSON 共用新 schema。
- 导入遇到结构错误时显示节点路径，例如“常用命令 / 服务管理 / 重启服务”，不替换当前内容。
- 网络库新增、编辑、删除、导入、导出继续复用现有 API 和冲突策略，但只接受新 schema。
- 导入、新建、清空、恢复示例后清理所有瞬时树展开状态，确保默认折叠。

## 错误处理与安全边界

- 所有移动操作先验证目标父节点、深度和同级关系，再一次性更新树；失败时不产生半更新状态。
- 删除父节点明确提示将删除整棵子树；快捷键冲突按全树计算并指出冲突条目。
- 生成前复用现有校验汇总；树深度、ID、字段或快捷键错误会阻止生成。
- 不引入外部依赖，不使用 `innerHTML` 拼接用户内容，沿用现有 DOM 创建和事件委托模式。

## 验证策略

- 核心测试：schema v2、递归遍历、深度限制、缩进/反缩进、同级移动、复制/删除子树、路径错误信息和快捷键全树冲突。
- 生成测试：递归导航、稳定锚点、默认命令全部显示、树顺序复制和内嵌 JSON。
- UI 契约测试：树节点 DOM、`aria-expanded`/`aria-level`、`indent-item`/`outdent-item` 动作、默认折叠和条目定位。
- 回归测试：现有网络 API、索引导航、重启脚本和 `wsl make` 必须通过。
- 手动浏览器回归：建立 4 级树，逐级缩进/反缩进、拖动同级顺序、展开祖先定位、复制和删除子树、导入错误 JSON，以及生成页导航与全部命令显示。
