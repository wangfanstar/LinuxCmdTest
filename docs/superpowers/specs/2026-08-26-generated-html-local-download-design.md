# 生成页本地下载 HTML 设计

## 目标

在 `HtmlPasteGen.html` 生成的独立 HTML 页面顶部固定功能栏中增加始终可见的“下载 HTML”按钮，让用户无需进入编辑模式即可把当前页面内容保存到本地。

## 方案选择

采用“顶部新增入口并复用现有导出函数”的方案。相比仅保留编辑模式入口，它减少操作步骤；相比复制一套下载逻辑，它不会产生两个导出结果不一致的问题。现有编辑模式中的“导出最新版 HTML”继续保留，两个按钮共同调用 `exportCurrentHtml()`。

## 交互与数据

- 新按钮位于生成页顶部固定 `hero-actions` 功能栏，文字为“下载 HTML”。
- 点击后使用现有安全文件名规则，以当前 `model.meta.filename` 下载 `.html` 文件。
- 下载文件必须包含当前运行时 `model`：包括编辑修改、导入 JSON、保存到文档的新条目。
- 临时复制篮和未保存的自定义片段不写入文档数据；这与现有“导出最新版 HTML”行为一致。
- 下载完成后在页面状态栏提示“已导出包含最新修改的 HTML。”；浏览器阻止下载时沿用现有浏览器行为，不新增网络请求。

## 实现边界

- 只修改生成页模板和事件绑定，不改变生成器工作台的“生成 HTML”按钮。
- 不删除现有 `reexport-button`，不增加第二套序列化或下载函数。
- 页面继续保持单文件、无外部依赖，可通过 `file://` 直接使用。

## 测试

- 契约测试验证生成结果包含顶部 `download-current-html-button`。
- 验证按钮监听器调用 `exportCurrentHtml()`。
- 继续使用监听器目标完整性检查，防止按钮 ID 与绑定代码不一致导致生成页初始化中断。
- 运行核心/UI/网络 API 测试、`git diff --check` 与 WSL `make`。
