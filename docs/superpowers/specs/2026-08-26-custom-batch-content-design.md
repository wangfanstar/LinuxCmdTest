# 多选复制篮自定义内容设计

## 目标

为生成的 HTML 页面增加自定义内容节点，让用户在多选命令组成的复制篮中插入任意纯文本，并能指定插入位置、调整顺序、编辑和删除。自定义内容默认只参与当前页面的复制；用户明确勾选保存后，才作为新条目写入当前文档 JSON。

## 用户流程

1. 用户选择多个命令，复制篮出现“＋自定义内容”。
2. 点击按钮打开弹窗，填写片段标题和多行内容，选择“开头 / 某条命令之后 / 末尾”。
3. 可选择“保存到文档”；勾选后选择目标分组并填写文档条目标题。
4. 点击“加入复制篮”加入当前输出序列，或点击“加入并复制”加入后立即复制。
5. 复制篮中自定义节点显示“自定义”标识，并提供编辑、上移、下移、删除；命令节点继续支持原有排序和移除。
6. 一键复制按照当前统一序列和现有分隔符规则生成剪贴板文本。

## 数据模型与生命周期

生成页面新增瞬时状态 `batchEntries`。节点结构如下：

```js
{ kind: 'item', id: '命令条目 ID' }
{ kind: 'custom', id: '临时片段 ID', title: '显示标题', content: '纯文本' }
```

`copyOrder` 仍保留为已选命令 ID 列表，用于兼容现有多选、快捷键和编辑状态；渲染复制篮前将命令节点与自定义节点合并成统一序列。自定义内容不写入 `paste-data` 或浏览器持久化存储，导入 JSON、重新生成或恢复原始内容时清空。

当用户勾选“保存到文档”并提交时，先将片段加入当前复制篮，再把内容作为新条目追加到所选分组，使用用户填写的条目标题生成新的条目 ID。写入文档失败时保留复制篮节点并显示错误，不能静默丢弃用户输入。

## 位置与排序规则

- 新片段位置选择为“开头”“某条命令之后”“末尾”。
- 位置转换为统一序列中的插入索引；若命令随后被删除，索引自动限制在当前序列范围内。
- 自定义节点和命令节点共用上移、下移、删除操作；移动不改变节点内容。
- 命令多选状态只由 `copyOrder` 表示，自定义节点不会被误计入“已选命令数量”。

## 界面与可访问性

- 复制篮操作区新增“＋自定义内容”按钮与自定义节点计数。
- 弹窗使用 `role="dialog"`、`aria-modal="true"`、标题关联和遮罩；支持 Escape 关闭并将焦点还给打开按钮。
- 内容标题和条目标题使用单行输入框；正文使用多行 `textarea`；目标分组使用 `select`。
- 空内容禁止提交；空标题使用“自定义片段”作为显示标题，保存到文档时必须填写条目标题。
- 桌面端为居中弹窗，窄屏为底部抽屉式布局；复制篮继续固定在视口底部并允许收起。

## 复制与错误处理

- 一键复制没有有效命令或自定义内容时，不修改系统剪贴板并播报提示。
- 自定义内容与命令内容统一经过现有分隔符（换行、空行、空格、自定义）拼接。
- 保存到文档前校验目标分组存在、条目标题非空；校验失败时弹窗保持打开并保留输入。
- 同一片段的“加入并复制”只复制一次，不重复追加。

## 测试策略

- 核心模型测试覆盖统一序列拼接、自定义节点插入、节点移动/删除、空内容校验和写入目标分组。
- 生成模板测试覆盖自定义按钮、弹窗字段、位置选项、节点编辑操作、临时状态清理和一键复制调用。
- 运行现有 HTML 生成器、网络库、索引导航测试与 `wsl make`，并执行 `git diff --check`。
- 浏览器烟雾测试覆盖：多选后添加片段、指定位置输出、编辑/移动/删除、加入并复制、保存到 JSON，以及 Escape 关闭弹窗。
