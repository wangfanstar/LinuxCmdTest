# HtmlPasteGen 网络库预览与固定操作设计

## 目标

修复 HtmlPasteGen 网络库中打开 HTML 可能出现空白页的问题，并让网络库与生成页面的高频操作在长页面滚动时保持可见。网络库导出默认启用覆盖保存，但覆盖同名文件前必须二次确认；生成的独立 HTML 默认展示完整命令内容。

## 方案

### 网络库 HTML 预览与打开

- 预览 iframe 继续加载 /html_paste/{文件名}，增加 load/error 状态反馈。
- “打开”按钮直接以目标 HTML URL 打开新标签，不再先创建 about:blank 再向新窗口写入 iframe，避免 noopener 场景产生空白页。
- 文件不存在、响应失败或浏览器阻止弹窗时，在网络库状态栏给出可操作提示。

### 网络库固定操作栏

- 将刷新、新建 JSON、导入选中 JSON、导出到网络库和覆盖选项放入网络库专用工具栏。
- 工具栏使用 position: sticky 固定到视口顶部，并设置安全层级和滚动阴影；移动端允许换行，按钮保持可点击。
- 搜索/类型筛选和文件列表留在网络库内容区，避免固定栏遮挡编辑区域。

### 默认覆盖与生成页完整命令

- 网络库“覆盖保存”复选框默认勾选；导出时仍弹出覆盖确认，取消即停止写入。
- 生成 HTML 的命令区域默认不使用折叠截断样式；“显示全部命令”仍保留为用户主动收起/展开的控制。
- 生成页面顶部操作区改为粘性工具栏，在下翻时继续显示搜索、筛选、主题、编辑、JSON 和复制相关按钮。

## 验证

- UI 合约检查默认覆盖、sticky 样式、直接 HTML 打开 URL、预览失败反馈和生成页默认展开行为。
- 运行 HtmlPasteGen 核心模型测试、UI 合约测试、HTTP 网络库合约测试及 wsl make。
- 使用本地浏览器验证网络库 HTML 预览可见、打开按钮不再落到空白页，并检查桌面/移动滚动布局。
